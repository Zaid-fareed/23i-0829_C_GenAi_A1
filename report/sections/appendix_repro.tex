\section{Reproducing the Results}\label{app:repro}
\textbf{Run the application.} Install Docker, then
\begin{verbatim}
git clone https://github.com/Zaid-fareed/
    23i-0829_C_GenAi_A1.git
cd 23i-0829_C_GenAi_A1
python scripts/download_models.py
docker compose up --build
\end{verbatim}
and open \code{http://localhost:3000}. The optional experiment browser is started with \code{docker compose --profile tracking up} (port 5000).

\textbf{Retrain.} \code{KAGGLE\_GUIDE.md} gives the notebook cells. The order is: split and manifests; Task~1 (\code{src.train.task1 optuna}, \code{final}); Task~2 classifier and specialists; Task~3; Task~4; then the evaluation and \code{src.export} scripts. Every \code{final} command accepts \code{--resume} to continue after an interrupted session.

\textbf{Evaluate.} \code{python -m src.eval.onnx\_full\_eval} scores the deployed ONNX models on the full 36,690-input manifest; \code{report/build\_figures.py}, \code{build\_tables.py}, \code{build\_qualitative.py} and \code{build\_analysis.py} regenerate every figure, table and number in this report, and \code{scripts/verify\_onnx\_results.py} re-measures the test results independently.

\textbf{Environment.} Training: Kaggle GPU T4 with PyTorch; development and inference: CPU. Seeds: 42 throughout.
