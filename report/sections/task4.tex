\section{Task 4: Style-Conditioned Face-to-Sketch cGAN}\label{sec:t4}
\textbf{Model.} The generator $\hat{y}=G(x,s)$ is a U-Net~\cite{ronneberger2015}: seven stride-2 encoder blocks (64--512 channels) reduce the $128\times128$ photograph to a $1\times1$ code, six transposed-convolution blocks with skip connections restore the resolution, and a final tanh layer gives a one-channel sketch (dropout 0.30 in the first three decoder blocks, 42.1\,M parameters, Fig.~\ref{fig:arch4}). The style $s\in\{1,2,3\}$ is a \emph{learned categorical embedding} (three vectors of 32 values) that enters the generator twice, as extra input channels and concatenated to the bottleneck, and the discriminator as extra input channels, so it is part of the model and not an interface label. The PatchGAN discriminator~\cite{isola2017} receives photograph, style map and a real or generated sketch and outputs a $14\times14$ map of patch logits (2.8\,M parameters).

\textbf{Losses and training.} The discriminator uses binary cross-entropy on logits (real pairs one, generated pairs zero; both losses are recorded), and the generator minimises $\mathcal{L}_G=\mathcal{L}_{adv}+\lambda_{L1}\mathcal{L}_{L1}(y,G(x,s))$; both use Adam ($\beta_1=0.5$). Optuna tuned both learning rates, batch size, base channels, dropout, embedding size and $\lambda_{L1}$ with 15-epoch trials (three completed, five pruned). The selected configuration (generator learning rate $1.5\times10^{-4}$, discriminator $8.6\times10^{-4}$, batch 8, 64 base channels, dropout 0.30, embedding 32, $\lambda_{L1}=121$) was trained for 100 epochs, logging discriminator real/fake loss, generator adversarial and L1 loss, and validation L1/SSIM/PSNR per epoch (Fig.~\ref{fig:curves4}). Every ten epochs the same eight validation photographs are rendered in all three styles and logged to MLflow (Fig.~\ref{fig:prog}).

Style~2 has the largest error (L1 \nFourLOnesTwo{} against \nFourLOnesOne{} for style~1 and \nFourLOnesThree{} for style~3) because its reference sketches use heavy dark strokes that a soft generator cannot match pixel by pixel; style-3 figures rest on only 46 pairs. The same photograph is rendered visibly differently in each style (Fig.~\ref{fig:styles}): style~2 darkest, style~1 lightest.

\textbf{Why the sketches are soft.} The average gradient magnitude of the generated sketches is only \nSharpShareAll\% of that of the real ones (measured on the test set). A sharper input helps a little and a blurred one hurts a little, but the effect is small next to this gap, so the limit lies in the training and not in the $128\times128$ input. Two causes fit the evidence. With 899 training pairs and $\lambda_{L1}=121$ the L1 term dominates and regresses to an average stroke; and in the selected Optuna trial the discriminator stayed near chance (loss near $\ln 2$), while in the 100-epoch run it did learn to separate real from fake (losses about 0.4, generator adversarial loss about 2) but the L1 term still dominates. This is the perception--distortion trade-off~\cite{blau2018}. A second recipe did not help (SSIM \nFourSSIMv{}, L1 \nFourLOnev{}) and was discarded; stronger adversarial or perceptual losses and more data were not explored.

\textbf{Failure cases.} The four lowest-SSIM test pairs (Fig.~\ref{fig:styles}) are portraits with long hair: three in style~2, where the reference draws hair with dense dark strokes and the generator a smooth grey mass (SSIM 0.18--0.20), and one in style~1 with thin crisp reference lines and a pale, blurred output (0.21). The faces remain recognisable, so these are failures of stroke detail, not identity. A thin line missing or shifted by a few pixels costs a large pixel error, which pixel metrics punish heavily on hair-rich style~2 subjects.
